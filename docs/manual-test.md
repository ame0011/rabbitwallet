# RabbitWallet 手動テスト手順 (Phase 0 ベースライン)

近代化リファクタリングの各 Phase で挙動が変わっていないことを確認するための
手動テスト手順書。修正前後で同じ操作を行い、表示・計算結果の差分を取る。

- ビルド: `.\gradlew.bat :app:assembleFlossDebug`
- APK: `app\build\outputs\apk\floss\debug\app-floss-debug.apk`
- インストール: `adb install -r app\build\outputs\apk\floss\debug\app-floss-debug.apk`
- proprietary フレーバー(`assembleProprietaryDebug`)は Dropbox / Open Exchange Rates
  の API キーを `gradle.properties` に設定した場合のみビルド可能

## テスト項目

共通の期待値: 例外クラッシュなし / 表示金額が一致 / 再起動後もデータ保持。
テストデータは必ず **新規作成** し、既存の実データを使わないこと。

### 1. 初回セットアップ

1. データをクリアして起動(`adb shell pm clear com.amessingularity.rabbitwallet`)
2. チュートリアルが流れ、通貨選択へ進む
3. EUR を選択して完了 → メイン画面に家計簿作成案内
4. 円・米ドルなど複数通貨を追加(通貨一覧から検索 → 追加)

### 2. 家計簿(財布)

1. 新規作成: 名前「現金」、通貨 EUR、開始残高 100.00 → 一覧に 100,00 EUR
2. 編集: 開始残高 200.00 に変更 → 残高が追従すること
3. アーカイブ → 一覧から非表示、アーカイブ表示で復元
4. 並び替えドラッグ → 順序が保存される
5. 削除 → 確認ダイアログ後、削除

### 3. 取引(収入・支出)

1. 支出登録: 分類「食費」金額 12.34 EUR → 概要の支出合計に反映
2. 収入登録: 金額 100.00 → 残高が増える
3. 編集で金額・分類・日付を変更 → 一覧と残高が追従
4. 削除 → 残高が戻る
5. 検索画面で金額・分類・期間・人・場所を条件に絞り込み
6. 期間詳細(日/週/月/年)で合計が明細の合計と一致

### 4. 移動(振替)

1. 家計簿 A → B へ 50.00 の移動(手数料 1.00 を併用)
2. A から 51.00 引き、B に 50.00 足されること、手数料が別扱いであること
3. 移動の編集・削除で残高が復元すること
4. 移動先に人を紐付け、一覧に人が表示されること

### 5. 繰り返し

1. 繰り返し取引作成: 毎朝 5.00 EUR の定期出費(FREQ=DAILY)
2. 翌日以降に承認待ちが発生 → 承認で通常取引化
3. 繰り返し移動も同様の手順で確認
4. 繰り返し元を停止/削除しても確定済み取引は残る

### 6. 分類

1. 親分類「食費」と子分類「外食」を作成し階層表示を確認
2. 子分類に取引を登録 → 親の集計に含まれること
3. 並び替え、アイコン変更
4. 使用中の分類を削除できないこと(システム分類も同様)

### 7. 予算

1. 支出予算: 分類「食費」今月 500.00 EUR、対象家計簿を指定
2. 取引登録後の進捗バー・残り金額が計算と一致
3. 収入予算でも同様に確認
4. 複数家計簿を予算に紐付けられること

### 8. 貯蓄・借金

1. 貯蓄作成(目標 10,000.00、開始 500.00)→ 達成率が概要に表示
2. 入金・出金として取引が記録され進捗が変わること
3. 借金作成(貸し/借り両方)→ 利息・期限日・関係者を表示

### 9. イベント・人・場所

1. イベント作成、期間設定、人を紐付け
2. 人を作成し取引/移動/借金に紐付け
3. 場所を作成し住所入力、地図で表示、取引・移動に紐付け
4. 地図画面でのマーカー表示

### 10. 添付ファイル

1. 取引に画像を添付 → プレビュー表示
2. 編集画面で残ったこと、削除で参照が消えること

### 11. 通貨ツール

1. 通貨一覧で追加・削除・お気に入り
2. 通貨コンバーターで EUR→USD 等の変換結果が妥当
3. 電卓から取引登録へ金額を引き継げる

### 12. バックアップと復元 (SAF + WorkManager)

1. 設定で自動バックアップを有効化(間隔・保持数・保存先ディレクトリ)
2. 保存先にバックアップディレクトリが作られ、ファイルが生成される
3. 一覧から手動バックアップ(エクスポート)
4. 別端末/クリーンインストール環境でインポート → 全データが復元
5. CSV/XLS/PDF のインポート・エクスポートが動作すること

### 13. ロック・設定

1. PIN/图案ロックを有効化 → 起動時に要求、解除できる
2. 外観設定(テーマ・色)が全画面に反映
3. 通貨表示設定(記号・桁数・グループ化・+/- 記号)が金額表示に反映
   - +/- 記号オフ時、色分けのみで符号を表す仕様に注意
4. 言語変更で主要画面が切り替わる

### 14. その他

1. カレンダー画面に取引・イベントが日別表示されること
2. 概要ウィジェットの表示(利用可能デバイスがあれば)
3. 通知チャネル(バックアップ完了・繰り返し承認)の確認(targetSdk 36 権限)
